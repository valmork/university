TOPIC 1


              Какое из приведенных утверждений верно ?

   1. Число внутренне устойчивых подмножеств меньше числа вершин
      графа.

   2. Вершина, имеющая петлю, принадлежит внутренне устойчивому
      подмножеству.

   3. Любые две вершины, принадлежащие внутренне устойчивому
      подмножеству не смежны.
TOPIC 2


               Какое из приведенных утверждений верно ?

    1. Граф может не иметь внешне устойчивых подмножеств.


    2. Вершина, имеющая петлю, не может принадлежать внешне
       устойчивому подмножеству.

    3. Вершина, не принадлежащая внешне устойчивому подмножеству,
       соединена дугой с какой-либо вершиной этого подмножества.
TOPIC 3


           Какое из приведенных утверждений несправедливо ?

    1. Граф, содержащий контуры нечетной длины, не имеет ядра.

    2. Граф без контуров обладает единственным ядром.

    3. Любое максимальное внутренне устойчивое подмножество
       симметрического графа является ядром.
TOPIC 4


      По какой матрице можно без дополнительных вычислений опреде-
      лить на сколько уровней разбивается данный граф.

             1. Матрица смежности.

             2. Матрица инциденций.

             3. Матрица кратчайших путей.

             4. Матрица наибольших путей.
TOPIC 5


                    Выберете правильный ответ.

       Число уровней не изменится при смене ориентации всех дуг на
       противоположную

             1. Для любого графа без контуров.


             2. Только для графа, у которого число вершин
                совпадает с числом уровней.

             3. Только для сильно связного графа.
TOPIC 6


            Какое из утверждений справедливо ?

      1. Только граф без контуров может обладать единственной
         функцией Гранди.

      2. Граф, не содержащий контуры нечетной длины, имеет и
         притом единственную функцию Гранди.

      3. Граф, содержащий контуры только четной длины, всегда
         имеет функцию Гранди.
