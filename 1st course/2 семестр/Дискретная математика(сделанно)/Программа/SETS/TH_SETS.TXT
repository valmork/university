!TOPIC 1

                         ПОНЯТИЕ  МНОЖЕСТВА


      Под  МНОЖЕСТВОМ  S  понимают  любое  собрание определенных и
 различимых  между  собой  объектов , мыслимое  как  единое целое.
 Эти объекты называются ЭЛЕМЕНТАМИ множества S.

      Символом  %Ue  обозначают  отношение  принадлежности, то  есть
 x %Ue S означает , что  элемент  x  принадлежит  множеству  S. Если
 элемент  x  не  принадлежит  множеству S , то пишем x %UE S.

      Множество,    элементами     которого    являются    объекты

 a%I1%S, a%I2%S,..., a%In%S   и  только они, обозначается  { a%I1%S, a%I2%S,..., a%In%S }.
!END
!TOPIC 2

     Сформулируем  два интуитивных  принципа, которые естественно
 считать  выполняющимися для произвольных множеств .

      ИНТУИТИВНЫЙ ПРИНЦИП ОБЪЕМНОСТИ.  Множества  А и В  считаются
 РАВНЫМИ, если они состоят из одних и тех же элементов .
      Если  множества  А и В  равны , то  пишут  А = В  и  А =%V1/ B в
 противном случае.

                              ПРИМЕР

      В  силу  принципа  объемности    { 2, 4, 6 } = { 4, 2, 6 } =
 = { 2, 4, 4, 6 };  {{ 1, 2 }} =%V1/ { 1, 2 },  так  как  единственным
 элементом  множества  {{ 1, 2 }}  является множество  { 1, 2 }, a
 множествo { 1, 2 } cocтоит из двух  элементов - чисел 1 и 2 .
!END
!TOPIC 3

      При  рассмотрении  способов   задания  множеств  естественно
 возникает  проблема  их  эффективного  описания.
      Под   ФОРМОЙ  ОТ  x  понимают  конечную  последовательность,
 состоящую из слов и символа x, такую, что если  каждое  вхождение
 x  в  эту  последовательность заменить  одним  и  тем  же  именем
 некоторого   предмета  соответствующего  рода,  то  в  результате
 получится истинное или ложное предложение.

                               ПРИМЕР

      Формами от  x  являются следующие предложения:  "3 делит x",

 " x%S2%I + 2x + 1 > x ",   " x%S2%I = 4 ",  " x - родственник  Иванова ".

 Напротив, предложения   " для всех x  x%S2%I - 4 = (x - 2)(x + 2) " и

 " существует такое x, что x > 0 "  не являются формами от x .
!END
!TOPIC 4

      Обозначим форму от x через Р(x) .

      ИНТУИТИВНЫЙ ПРИНЦИП АБСТРАКЦИИ.  Любая форма Р(x) определяет
 некоторое  множество  А, а  именно  множество  тех  и  только тех
 предметов  a,  для   которых   Р(a) - истинное предложение.

      Для  множества   А,  определяемого   формой   Р(x),  принято
 обозначение
                         А = { x │ P(x) }.

                              ПРИМЕР

      Используя  введенное   обозначение,  считают,  что  следующие
 множества совпадают: { x │ x - положительное число , меньшее 9 } и
 { 1, 2, 3, 4, 5, 6, 7, 8 };   { x │ x - четное число } - множество
 четных чисел.
!END
!TOPIC 5

     Cимволом %UP обозначают ОТНОШЕНИЕ ВКЛЮЧЕНИЯ между множествами,
 то есть пишут А %UP В, если каждый элемент множества А есть элемент
 множества  В. Тогда говорят, что  A  есть ПОДМНОЖЕСТВО множества B.
 Если  А %UP B  и  А =%V1/ В,  то  говорят,  что   А   есть  СОБСТВЕННОЕ
 ПОДМНОЖЕСТВО  В  и пишут  А %Up В.

                              ПРИМЕР
      Множество  четных  чисел  есть подмножество  множества целых
 чисел;  множество рациональных чисел  есть подмножество множества
 действительных чисел;  { 1, 2 } %UP { 1, 2, 3, 4 }.

      Выполняются  следующие  свойства  включения:     а)  A %UP A ;
 б) если A %UP B  и  B %UP A, то A = B;   в) если A %UP B  и  B %UP C , то
 A %UP C, каковы бы ни были множества  A, B, C.
      Mножество,  не содержащее  элементов,  называется  пустым  и
 обозначается   0%V1%U/.  Пустое  множество  есть
 подмножество  любого  множества.
!END
!TOPIC 6

                    ОПЕРАЦИИ  НА  МНОЖЕСТВАХ

      Опишем основные операции  на  множествах, которые  позволяют
 получить  новые  множества из уже существующих.

      ОБЪЕДИНЕНИЕМ  множеств  А  и  В называется множество  А %UO В,
 все элементы которого являются элементами  множества  А или В

              А %UO В = { x │ x %Ue A  или  x %Ue В }.

      ПЕРЕСЕЧЕНИЕМ  множеств  А  и  В называется множество  А %UR В,
 элементы  которого  являются  элементами  обоих множеств  А  и  В
 одновременно

              А %UR В = { x │ x %Ue A  и  x %Ue В }.
!END
!TOPIC 7

                              ПРИМЕР

         { 1, 2, 3 } %UO { 1, 3, 4 } = { 1, 2, 3, 4 };
         { 1, 2, 3 } %UR { 1, 3, 4 } = { 1, 3 }.

      Очевидно,  что  выполняются   включения   А %UR В %UP А %UP А %UO В,
 А %UR В %UP В %UP А %UO В.

      ОТНОСИТЕЛЬНОЕ  ДОПОЛНЕНИЕ  множества  А до множества B - это
 множество  B \ A  всех  тех  элементов  множества  B, которые  не
 принадлежат  множеству  А

                   B \ A = { x │ x %Ue B  и  х %UE А }.

      CИММЕТРИЧЕСКАЯ  РАЗНОСТЬ  множеств  А  и  В - это  множество

                   А + В = (А \ В) %UO (B \ A).
!END

                        БИНАРНЫЕ ОТНОШЕНИЯ

      УПОРЯДОЧЕННАЯ  ПАРА   <x, y>   интуитивно  определяется  как
 совокупность, состоящая из двух предметов  х и у, расположенных в
 определенном  порядке. Две пары <x, y> и <u, v> считаются равными
 тогда и только тогда, когда  х = u,  a  у = v.

      БИНАРНОЕ  (или двуместное)  ОТНОШЕНИЕ   R  -  это  множество
 упорядоченных пар. Если R есть некоторое отношение, и пара <x, y>
 принадлежит  этому  отношению , то  наряду  с записью  <x, y> %Ue R
 будем  употреблять  запись  x R y.  Элементы  х  и  у  называются
 координатами или компонентами отношения  R.

      ОБЛАСТЬЮ  ОПРЕДЕЛЕНИЯ  бинарного  отношения   R   называется
 множество D(R) = { x │ существует такое у, что  x R y }.
!END
!TOPIC 22

      ОБЛАСТЬЮ   ЗНАЧЕНИЙ   бинарного   отношения   R   называется
 множество O(R) = { y │ существует такое x, что x R y }.

                             ПРИМЕРЫ
      1. Множество   {<1, 2>, <2, 4>, <3, 3>, <2, 1>}  -  бинарное
 отношение.

      2. Отношение равенства  на  множестве  действительных  чисел
 есть  множество  {<x, y> │ x и y действительны и x равно y}.  Для
 этого  отношения  есть  специальное  обозначение  " = ".  Область
 определения  D(R)  совпадает с областью значений  O(R) и является
 множеством действительных чисел.

      3. Отношение   "меньше, чем"   на   множестве  целых  чисел:
 {<x, y> │ для целых чисел  x и y  найдется положительное число z,
 такое,  что    x + z = y}.   Для  этого  отношения   используется
 специальное обозначение  " < ". Здесь  D(R)  совпадает с  O(R)  и
 является множеством целых чисел.
!END
!TOPIC 23



      ПРЯМЫМ    ПРОИЗВЕДЕНИЕМ    МНОЖЕСТВ   Х   и   Y   называется

 совокупность всех упорядоченных пар  <x, y>,  таких, что   х %Ue Х,

 y %Ue Y.   Обозначается   прямое   произведение  множеств   X  и  Y

 через  X x Y.

      Каждое отношение  R  есть подмножество  прямого произведения

 некоторых множеств  X и Y, таких, что  D(R) %UP X,  O(R) %UP Y.  Если

 Х = Y, то говорят, что  R  есть  отношение на множестве  Х.
!END

 что х%Ii%S %Ue X%Ii%S, i=1,2...n. Обозначается прямое произведение множеств

 Х%I1%S, X%I2%S,..., Х%In%S        через        Х%I1%S x X%I2%S x ... x Х%In%S.       Если

 Х%I1%S = X%I2%S = ... = Х%In%S,   то   пишут     Х%I1%S x X%I2%S x ... x Х%In%S = X%Sn%I.

 Любое  n-местное отношение есть подмножество прямого произведения

 некоторых множеств  Х%I1%S, X%I2%S,..., Х%In%S.
!END

!TOPIC 29

     Как в математике, так и  в обыденной жизни  мы  рассматриваем
 разные типы отношений эквивалентности .

                             ПРИМЕРЫ

      1. Отношение равенства на множестве действительных чисел R -
 отношение эквивалентности.  Оно рефлексивно,  так как  для любого
 действительного числа  x  выполняется  x = x,  сиимметрично,  так
 как, если  x = y, то  y = x  и транзитивно, так как, если  x = y,
 y = z, то  x = z.

      2. Отношение подобия на множестве  треугольников - отношение
 эквивалентности.

      3. Отношение   x < y   на множестве  действительных чисел не
 рефлексивно, не симметрично, но транзитивно на этом множестве.
!END
!TOPIC 30


      4. Отношение сравнимости по модулю натурального числа  n  на
 множестве  целых  чисел  Z:  x %U= y (mod n)  тогда и только тогда,
 когда  x - y  делится на  n. Это отношение рефлексивно на  Z, так
 как для любого   x %Ue Z    x - x = 0  и, следовательно, делится на
 n;  это  отношение  симметрично:  если  x - y  делится  на  n, то
 y - x  делится  на  n;  это  отношение  транзитивно:  если  x - y
 делится на  n, то для некоторого целого  t%I1%S  имеем  x - y = t%I1%S n,

 если  y - z  делится  на  n, то  для некоторого целого  t%I2%S  имеем

 x - y = t%I2%S n. Отсюда x - z = (t%I1%S + t%I2%S) n, то есть  x - z  делится
 на  n.

     5. Отношение принадлежности к одной  студенческой  группе на
 множестве студентов - отношение эквивалентности.

      Множество  X с заданным на нем частичным (линейным порядком)
 называется  ЧАСТИЧНО (ЛИНЕЙНО) УПОРЯДОЧЕННЫМ.

      Рассмотрим непустое конечное множество  Х, на котором задано
 отношение частичного порядка  %U<. Будем писать  х < y, если  х %U< у
 и  х =%V1/ у. Говорят,  что  элемент  у  покрывает  элемент  х,  если
 х < у  и не существует такого элемента  u, что   х < u < у. Тогда
 х < у   равносильно   тому ,  что   существуют   такие   элементы
 х%I1%S, х%I2%S,...,х%In%S,что х = х%I1%S < х%I2%S <...< х%In%S = у, где х%Ii+1%S покрывает x%Ii%S.

 Мы  можем  изобразить  любое  частично  упорядоченное множество в
 виде схемы,  в которой  каждый  элемент  изображается  точкой  на
 плоскости и, если  у  покрывает  х,  то точки  х и у  соединяются
 отрезком,  причем  точка  х  расположена  ниже  у.   Такие  схемы
 называются ДИАГРАММАМИ ХАССЕ.
